## Featured projects

### RAPID: Remote Access Platform for Intelligent Driving
*Capstone project, 2024 to 2025*

An LTE-controlled delivery robot with real-time remote driving, live video streaming and GPS tracking.

- Web control platform built with React, Tailwind CSS, WebRTC and Firebase for secure, low-latency communication.
- Embedded software on a Raspberry Pi in Python and ROS2, integrating motor control, the camera feed and GPS.
- Tested and validated over 4G LTE, evaluating latency, reliability and real-world feasibility.

### AI-Powered Stock Tracker
*2025*

An app for real-time asset details, performance metrics and market trends, with AI-driven insights on stock behavior, portfolio performance and user preferences.

- Scalable architecture focused on data accuracy, security and low-latency market data visualization.

### Mealer
*Team project, 2022*

A tiffin service and delivery app built in an introductory software engineering course, where I led the team.

- Improved user engagement by 25% with a more user-friendly interface.
