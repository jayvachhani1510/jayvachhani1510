# Hi, I'm Jay

I'm a final-year Computer Engineering student at the University of Ottawa, based in Ottawa, Canada. I build robotics and web applications, from embedded software on a Raspberry Pi to real-time web control platforms.

## Projects

- **RAPID (Remote Access Platform for Intelligent Driving):** my capstone project. An LTE-controlled delivery robot with real-time remote control, live video streaming and GPS tracking. The web control platform uses React, Tailwind CSS, WebRTC and Firebase, and the embedded software runs on a Raspberry Pi with Python and ROS2.
- **AI-Powered Stock Tracker:** an app for viewing real-time asset details, performance metrics and market trends, with AI-driven insights on stock behavior and portfolios.
- **Mealer:** a tiffin service and delivery app that I led a team to build in an introductory software engineering course.

## Tech

React, Tailwind CSS, WebRTC, Firebase, Python, ROS2, Raspberry Pi
