## Featured projects

### BullDog: markets and portfolio app
*Full-stack web application, 2025 to present. Source: private repository.*

A markets app for stocks, ETFs, crypto, indices, commodities and forex, with live quotes, chart-first symbol pages, a screener, watchlists, price alerts and a tracked portfolio, plus an Alpaca paper-trading account. Every number comes from a real source, and when a source is unavailable the app says so instead of inventing a value.

- **Front end:** React 18 and Vite with interactive charts (indicators, drawing tools, saved templates, replay), two visual themes and a command palette.
- **Back end:** Node.js and Express API with a live-price WebSocket, Node's built-in SQLite for accounts, JWT sessions, rate limiting and Helmet security headers.
- **Data:** Yahoo Finance, Nasdaq, SEC EDGAR, CoinGecko and DeFi Llama. Trading goes through Alpaca's paper API only, and the client refuses any live-trading host.
- **Quality and delivery:** Jest and React Testing Library on the front end, Jest and supertest on the API, ESLint with zero warnings allowed, GitHub Actions CI, a Docker image, and scripted deployment to a Google Cloud VM.

### RAPID: Remote Access Platform for Intelligent Driving
*Capstone project, 2024 to 2025*

An LTE-controlled delivery robot with real-time remote driving, live video streaming and GPS tracking.

- **Web control platform:** React, Tailwind CSS, WebRTC and Firebase for secure, low-latency communication.
- **Embedded software:** Python and ROS2 on a Raspberry Pi, integrating motor control, the camera feed and GPS.
- **Validation:** tested over 4G LTE, evaluating latency, reliability and real-world feasibility.
